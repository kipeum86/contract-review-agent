## 개인 프로젝트

이 저장소는 Kipeum Lee의 **독립적인 개인 프로젝트**입니다. 어떤 로펌, 고용주, 조직의 후원, 보증, 제휴도 받지 않습니다. 모든 의견, 설계 결정, 콘텐츠는 전적으로 저 개인의 것입니다.

## 법률 자문 아님

이 저장소의 어떤 내용도, 그리고 에이전트가 생성한 검토 보고서, 레드라인 제안, 리스크 등급, 기타 모든 산출물도 법률 자문에 해당하지 않습니다. 이러한 결과물은 **정보 제공 및 보조 목적**으로만 제공됩니다. 자격 있는 법률 전문가의 조언을 대체하는 것으로 의존해서는 안 됩니다.

## AI의 한계 — 환각과 오류

이 프로젝트는 대규모 언어 모델(Claude)을 기반으로 합니다. LLM은 실제로 **환각, 사실 오류, 잘못된 법률 분석**을 만들어낼 수 있습니다. 결과물에는 다음과 같은 문제가 있을 수 있습니다:

- 계약 조항을 잘못 식별하거나 잘못 분류할 수 있음
- 중요한 리스크나 의무를 놓칠 수 있음
- 법적으로 부정확한 제안을 생성할 수 있음
- 존재하지 않는 법령, 판례, 계약 조항을 꾸며낼 수 있음

어떤 결과물이든 의존하거나 조치를 취하기 전에 **반드시 자격 있는 사람이 직접 검토하고 검증해야 합니다**. 에이전트는 제안할 뿐이고, 결정은 사람이 내립니다.

## 데이터 보안 및 프라이버시

모든 처리는 **로컬 파일시스템에서** 이루어지며, 외부 서버나 데이터베이스는 사용하지 않습니다. 다만 에이전트는 LLM API 호출을 수행하므로 **계약서 텍스트는 모델 제공자**(Anthropic)에게 전송됩니다.

기밀 문서를 포함한 실제 법률 업무에 이 도구를 사용하려는 경우:

- **최소한**, 무료 티어 또는 소비자용 플랜이 아닌 **상용 API 키**를 사용해 표준 상용 데이터 처리 약관이 적용되도록 하세요.
- **이상적으로는**, **Zero Data Retention (ZDR) 계약이 포함된 Enterprise 플랜**을 사용하세요. 다만 ZDR이 **완전한 보장**은 아닙니다. 데이터는 여전히 제공자 인프라를 통과합니다. 조직 요구사항에 부합하는지 판단하려면 Anthropic의 [ZDR 및 데이터 처리 문서](https://code.claude.com/docs/en/zero-data-retention)를 직접 검토하세요.
- **반드시**, 기밀정보, 특권정보, 개인정보를 어떤 AI 도구로든 처리하기 전에 조직의 **보안, 컴플라이언스, IT 부서**와 먼저 협의하세요.
- 현재 플랜에 적용되는 최신 조건은 [Anthropic의 데이터 사용 정책](https://www.anthropic.com)에서 확인하세요.
